## <img src="https://raw.githubusercontent.com/rosgear/rg-be-signin/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Авторизация в Панели управления»

Модуль входит в состав Панели управления GePanel.

Модуль реализует механизм аутентификации и авторизации пользователей для получения доступа к функционалу Панели управления GePanel.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-signin
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-signin": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-signin/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

<a name="english"></a>
## <img src="https://raw.githubusercontent.com/rosgear/rg-be-signin/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Sign in to Control Panel»

The module is part of the GePanel Control Panel.

The module implements a mechanism for authentication and authorization of users to gain access to the functionality of the GePanel Control Panel.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-signin
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-signin": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-signin/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
